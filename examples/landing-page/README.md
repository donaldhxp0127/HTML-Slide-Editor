# Landing Page tutorial

Adapted from [Start Bootstrap Landing Page](https://github.com/StartBootstrap/startbootstrap-landing-page), MIT license. The original template's ocean masthead, three-column features, image showcase and testimonials are reorganized into five editable 1280 × 720 slides. Text and layout are adapted for learning Slide Studio; signup forms, third-party scripts, fonts and CDN dependencies are removed.

The JPEGs are resized copies of the original template's demonstration assets. Keep `LICENSE` when redistributing. Edit `index.html` and run `node scripts/build-tutorial.mjs` from the repository root to regenerate `slide-editor/tutorial.html`. The generated tutorial embeds images and the license so exported HTML remains portable and works offline.
