# Slide Studio

A local visual editor for HTML slide decks, with English, Japanese, and Chinese UI support.

See the main [English README](../README.md) for setup, editing, source navigation, and limitations, or read the [简体中文说明](../README.zh-CN.md).

From the repository root, run:

```sh
python3 slide-editor/server.py
```

Then open http://127.0.0.1:8765/ in your browser. Python 3.9+ is required; no additional packages are needed.
